# Security Policy

## Supported versions

Security fixes are provided for the current npm `latest` release of
`@semlens/cli`.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory reporting flow for this repository. Include affected CLI
version, reproduction steps, impact, and any suggested mitigation.

The CLI contains no hosted Semlens service credentials. Hosted-service
security reports should use the reporting channel published by Semlens.
